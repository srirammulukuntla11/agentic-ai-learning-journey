🤖 Built a Multi-Document Knowledge Base Agent using n8n + Gemini
Problem:
Traditional document search becomes difficult when information is spread across multiple documents. Users need a way to ask questions naturally and retrieve information from a unified knowledge base.
Solution:
I built a Knowledge Base Agent using n8n, Google Gemini, OpenAI Embeddings, and a Vector Store that can search across multiple documents and generate answers using the retrieved information.
Workflow:
📄 Upload multiple knowledge documents
↓
📚 Load and process documents
↓
✂️ Split documents into chunks
↓
🧠 Generate embeddings
↓
🗄️ Store knowledge in a vector store
↓
🤖 AI Agent receives the user's question
↓
🔍 Knowledge Base Search retrieves relevant information
↓
💬 Gemini generates the final answer
How it works:
The system creates embeddings for the uploaded documents and stores them in a vector store. When a user asks a question, the AI Agent uses the Knowledge Base Search tool to retrieve relevant information from the available knowledge and passes it to Gemini to generate the response.
Concepts Implemented:
🔹 Multi-document knowledge base
🔹 RAG
🔹 Vector embeddings
🔹 Semantic search
🔹 Document chunking
🔹 AI Agent + Tool usage
🔹 Vector Store
🔹 LLM-based answer generation
🔹 n8n workflow automation
Result:
Successfully tested the agent across multiple knowledge areas including Leave Policy, Work From Home Policy, and Employee Benefits, with the agent retrieving relevant information and generating contextual answers. ✅
